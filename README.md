# E-CUSTOMS CNC Woodworks

A static, mobile-friendly portfolio site built with HTML, CSS, and JavaScript. It has no application backend, database, or runtime dependencies.

## Run locally

From the project directory:

```powershell
npm run dev
```

Open [http://localhost:4173/](http://localhost:4173/). Python is used only for the local preview server; the deployed site is static.

## Deploy with GitHub Pages

1. Push the project files to a GitHub repository.
2. In the repository, open **Settings → Pages**.
3. Choose **Deploy from a branch**, select the publishing branch, and choose the repository root.
4. Save and wait for GitHub Pages to publish the site.

The site entry point is `index.html`; keep `styles.css`, `script.js`, and `images/` beside it. Image paths are case-sensitive after deployment, so preserve the filenames and capitalization.

## Contact links

The WhatsApp and email links are in the contact section of `index.html`. Update them there if the official contact details change.
